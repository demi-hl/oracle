Windows SmartScreen will warn on first run. The installer carries electron-builder's generated signature, not a CA-issued code-signing certificate, so Windows shows "unknown publisher": choose More info, then Run anyway. Verify the checksum below first.

The macOS build is signed and notarized with Developer ID 5BV985Z9LJ, and the ticket is stapled, so it opens with no Gatekeeper prompt. Verified by mounting the dmg and asking Gatekeeper directly: Oracle.app: accepted · source=Notarized Developer ID.

Checksums are printed so you can verify what the gate served you: sha256sum Oracle-0.1.0.AppImage. The desktop shell holds no keys and broadcasts nothing; it prepares transactions your wallet signs.
